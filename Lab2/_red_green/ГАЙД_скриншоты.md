# Гайд: какие скриншоты снять в Visual Studio и куда вставить (ЛР2)

Нужны ровно 2 скриншота. Всё остальное в отчёте уже готово (рисунки 3–5 – это HTML-отчёт покрытия из браузера, их менять не надо).

## Подготовка (один раз)
1. Visual Studio 2022 + .NET 8 SDK (в Visual Studio Installer: «Разработка классических приложений .NET» или «ASP.NET»; SDK 8.0 должен быть в списке).
2. Распакуйте архив, откройте `Lab2\Lab2.sln` двойным щелчком.
3. Сборка: Ctrl+Shift+B. Должно быть «Сборка: успешно: 2».
4. Откройте Test Explorer: меню «Тест» -> «Обозреватель тестов» (или Ctrl+E, T).
5. Расширьте окно Test Explorer (перетащите во всю высоту/ширину, раскройте дерево Lab2.Tests -> Lab2.Tests -> OrderServiceTests), чтобы были видны сводка и список тестов.

## Скриншот 1 – RED (все тесты красные)
1. Откройте `Lab2.Core\OrderService.cs`. Сделайте копию файла (на всякий случай): в папке `_red_green` лежит `OrderService.GREEN_real.cs.txt` – это то же самое.
2. Выделите всё содержимое файла (Ctrl+A) и вставьте код из `_red_green\OrderService.RED_stub.cs.txt` (заглушка с `throw new NotImplementedException();`). Ctrl+S.
3. В Test Explorer нажмите «Запустить все тесты» (зелёная двойная стрелка, или Ctrl+R, A).
4. Должно быть: красные значки, внизу/справа «39 не пройдено» (в русской VS) / `39 Failed`. Если у вас в окне видна только часть тестов, это нормально, но сводка должна быть видна.
5. Сделайте скриншот окна Test Explorer (Win+Shift+S). Сохраните как `red.png`.

## Скриншот 2 – GREEN (все тесты зелёные)
1. Верните реальный код: Ctrl+A в `OrderService.cs`, вставьте содержимое `_red_green\OrderService.GREEN_real.cs.txt`, Ctrl+S (или `git checkout Lab2/Lab2.Core/OrderService.cs`).
2. Снова «Запустить все тесты».
3. Должно быть: зелёные значки, «39 пройдено».
4. Скриншот того же окна в тех же размерах. Сохраните как `green.png`.

## Куда вставить в отчёт (Лабораторная_работа_2.docx)
- Раздел 2 «РЕАЛИЗАЦИЯ UNIT-ТЕСТОВ», в самом конце (примерно стр. 9), сразу после листинга 8 «Заглушка OrderService для фазы Red».
- **Рисунок 1 – Фаза Red** -> замените картинку на `red.png`.
- **Рисунок 2 – Фаза Green** -> замените картинку на `green.png`.
- Как заменить в Word: щёлкните по картинке -> правая кнопка -> «Изменить рисунок» -> «Из файла» -> выберите файл. Подписи и размер сохранятся. Если картинка вышла слишком большой: Формат рисунка -> ширина 14 см.
- Подписи «Рисунок 1 – Фаза Red…», «Рисунок 2 – Фаза Green…» и текст вокруг менять не нужно.

## Что НЕ надо делать
- Не вставляйте скриншоты из чужих работ и не рисуйте их: в отчёте должны быть результаты вашего проекта.
- Если число тестов в вашей Visual Studio отличается от 39 (Test Explorer иногда по-другому группирует параметризованные тесты), перепишите число в тексте и подписях под то, что видите на скриншоте. Ориентир: 22 тестовых метода, 39 запусков.
